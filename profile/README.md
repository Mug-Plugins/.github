# 👋 Welcome to Mug-Plugins

专注打造轻量、实用的浏览器油猴脚本（UserScript）与前端增强插件，推荐使用 **[ScriptCat（脚本猫）](https://docs.scriptcat.org/)** 运行与管理（同时兼容 Tampermonkey / Violentmonkey）。

## 🚀 快速使用

1. 安装浏览器脚本管理器：推荐 **[ScriptCat（脚本猫）](https://docs.scriptcat.org/)**。
2. 点击上方表格中的 **「直接安装」** 链接即可一键导入脚本；或进入对应仓库查看详细说明与源码。
